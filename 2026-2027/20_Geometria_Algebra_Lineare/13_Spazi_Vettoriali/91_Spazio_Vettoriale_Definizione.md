# Spazio vettoriale: definizione

> [!abstract] Definizione 11.2
> Uno **spazio vettoriale** su un campo $\mathbb{K}$ è un insieme $V$ dotato di due operazioni:
> - (operazione **interna**) $+:\ V\times V\to V$
> - (operazione **esterna**) $\cdot:\ \mathbb{K}\times V\to V$
>
> che soddisfano le seguenti proprietà:

| | Proprietà | Enunciato |
|---|---|---|
| (V1) | associativa della somma | $\forall\,\underline{v}_1,\underline{v}_2,\underline{v}_3\in V:\ (\underline{v}_1+\underline{v}_2)+\underline{v}_3=\underline{v}_1+(\underline{v}_2+\underline{v}_3)=\underline{v}_1+\underline{v}_2+\underline{v}_3$ |
| (V2) | commutativa della somma | $\forall\,\underline{v}_1,\underline{v}_2\in V:\ \underline{v}_1+\underline{v}_2=\underline{v}_2+\underline{v}_1$ |
| (V3) | esistenza dell'elemento neutro | $\exists\,\underline{0}\in V$ t.c. $\forall\,\underline{v}\in V:\ \underline{v}+\underline{0}=\underline{0}+\underline{v}=\underline{v}$ |
| (V4) | esistenza dell'elemento opposto | $\forall\,\underline{v}\in V\ \exists\,\underline{v}'\in V$ t.c. $\underline{v}+\underline{v}'=\underline{v}'+\underline{v}=\underline{0}$ |
| (V5) | distributiva a destra | $\forall\,\lambda\in\mathbb{K}\ \forall\,\underline{v}_1,\underline{v}_2\in V:\ \lambda(\underline{v}_1+\underline{v}_2)=\lambda\underline{v}_1+\lambda\underline{v}_2$ |
| (V6) | distributiva a sinistra | $\forall\,\lambda_1,\lambda_2\in\mathbb{K}\ \forall\,\underline{v}\in V:\ (\lambda_1+\lambda_2)\underline{v}=\lambda_1\underline{v}+\lambda_2\underline{v}$ |
| (V7) | associativa del prodotto | $\forall\,\lambda_1,\lambda_2\in\mathbb{K}\ \forall\,\underline{v}\in V:\ (\lambda_1\lambda_2)\underline{v}=\lambda_1(\lambda_2\underline{v})=\lambda_2(\lambda_1\underline{v})$ |
| (V8) | esistenza dell'elemento neutro del prodotto | $\forall\,\underline{v}\in V:\ 1\,\underline{v}=\underline{v}$ |
