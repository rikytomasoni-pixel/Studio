# Proprietà delle operazioni tra vettori

> [!abstract] Teorema (Proposizione)
> Le operazioni fra vettori ([[03_Operazioni_tra_Vettori]]) soddisfano le formule seguenti:
> 1. $(u+v)+w = u+(v+w)$ — associativa
> 2. $u + v = v + u$
> 3. $u + 0 = u = 0 + u$
> 4. $u + (-u) = 0 = (-u) + u$
> 5. $1u = u$
> 6. $s(tu) = (st)u$
> 7. $t(u+v) = tu + tv$
> 8. $(s+t)u = su + tu$

> [!note] Osservazione
> Le stesse proprietà ritornano per le matrici: [[06_Somma_tra_Matrici]] e [[07_Prodotto_di_una_Matrice_per_uno_Scalare]].
