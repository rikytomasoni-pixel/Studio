# Base di uno spazio vettoriale

> [!abstract] Definizione 13.4
> Sia $(V,+,\cdot)$ uno spazio vettoriale su un campo $\mathbb{K}$. Un insieme di vettori $\{\underline{v}_1,\dots,\underline{v}_n\}$ si dice **base** di $V$ se $\{\underline{v}_1,\dots,\underline{v}_n\}$ è un insieme di **generatori linearmente indipendenti**.

In altre parole, una base è:
- un [[96_Insieme_di_Generatori|insieme di generatori]]: $V=\operatorname{Span}(\underline{v}_1,\dots,\underline{v}_n)$;
- formata da [[98_Vettori_Linearmente_Indipendenti|vettori linearmente indipendenti]].

Esempio visto a lezione: $\left\{\begin{bmatrix}1\\0\\0\end{bmatrix},\begin{bmatrix}-2\\1\\0\end{bmatrix},\begin{bmatrix}0\\1\\1\end{bmatrix}\right\}$ è una base di $\mathbb{R}^3$ ([[99_Dipendenza_Lineare_e_Vettori_Ridondanti]]). Un altro esempio è la base canonica di $\mathbb{R}^2$ ([[102_Dimensione_di_uno_Spazio_Vettoriale]]).

La proprietà che motiva la definizione (rappresentazione unica) è il [[101_Teorema_di_Unicita_della_Rappresentazione_rispetto_a_una_Base]].
