# Teorema di struttura delle soluzioni di un sistema lineare

> [!abstract] Teorema 10.1 (Teorema di struttura delle soluzioni di un sistema lineare)
> **HP:**
> - $A\underline{x}=\underline{b}$ sistema lineare **risolubile**;
> - $\underline{v}_0$ è una soluzione del sistema.
>
> **TH:** tutte e sole le soluzioni di $A\underline{x}=\underline{b}$ sono del tipo
> $$\underline{x}=\underline{v}_0+\underline{v}_H$$
> dove $\underline{v}_H$ è un elemento di $\ker(A)$.

In altre parole: l'insieme delle soluzioni è $\underline{v}_0+\ker(A)$, cioè una soluzione particolare più tutte le soluzioni del sistema omogeneo associato ([[84_Nucleo_e_Sistema_Omogeneo_Associato]]).
