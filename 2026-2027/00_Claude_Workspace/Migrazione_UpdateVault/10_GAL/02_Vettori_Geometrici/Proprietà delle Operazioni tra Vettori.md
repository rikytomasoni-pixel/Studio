# Proprietà delle Operazioni tra Vettori

> [!abstract] Teorema (Proposizione)
> Le operazioni fra vettori ([[Operazioni tra Vettori]]) soddisfano le formule seguenti:
> 1. $(u+v)+w = u+(v+w)$ — associativa
> 2. $u + v = v + u$
> 3. $u + 0 = u = 0 + u$
> 4. $u + (-u) = 0 = (-u) + u$
> 5. $1u = u$
> 6. $s(tu) = (st)u$
> 7. $t(u+v) = tu + tv$
> 8. $(s+t)u = su + tu$

> [!note] Osservazione
> Le stesse proprietà ritornano per le matrici: [[Somma tra Matrici]] e [[Prodotto di una Matrice per uno Scalare]].
