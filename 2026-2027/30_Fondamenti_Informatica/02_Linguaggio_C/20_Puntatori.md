# Puntatori
Ogni dato è assegnato ad un indirizzo di memoria.
Il puntatore è una *variabile che ospita un indirizzo di memoria*

- & operatore di referenziazione (associa alla variabie l'indirizzo)
- %p carattere di formato

```C
float x = 3;
printf("%p\n",&x);
```
